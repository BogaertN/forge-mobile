Mobile Identity Vault —
A local encrypted secret store on this phone, not the full Identity Vault service. Passphrase: at least 8 characters. Forge cannot recover a lost passphrase; a forgotten one can only be reset by discarding the sealed values.
Sensitive values (PINs, passwords, card numbers, keys…) are redacted at ingestion: the kernel, trace, memory, receipts and exports only ever see the word “sealed”. The value itself is encrypted on this device (AES-GCM-256, key from your passphrase via PBKDF2-SHA-256) and is never shown in chat.
EchoForge · Tool Bench no LLM
EchoForge is the kernel's tool bench. Every tool is declared by a manifest and runs only when the kernel selects one of its predicate frames. The permission service decides each call. Results come back as evidence, never as authority, and every call is hash-chained. The old LLM advisory lane (echoforge-advisory) stays excluded.
