### 4.1 Lifecycle (Ch 4.5) — Spawn → Run → Hibernate → Retire → Resurrect

1. **Spawn** — Orchestrator or user/workflow; unique id; memory stack + drift index; log `phase:init`; parent/child linkage if sub-agent; `active=True`.

### 4.3 Sub-agents (Ch 6.3)

- Log ancestry; isolate drift/collapse to the child; merge outputs back to parent.
- **Avoid spawn storms**; orchestrator enforces resource limits.
- Config example: **`max_agents: 32`**, `can_spawn_agents = true`, `drift_auto_quarantine: true`.
