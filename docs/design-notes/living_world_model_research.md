# Forge Mobile — Living World Model: Prior Art & Design Gaps
*(Researched Oct 30, 2026. URLs marked ✓ were checked and loaded; ⚠ = the publisher blocks scripted fetches, but the DOI is real.)*

## 1. Prior art: short summaries

| System / idea | What it does | Lesson for Forge |
|---|---|---|
| **NELL**, CMU (2010–2018). ✓ https://www.cs.cmu.edu/~acarlson/papers/carlson-aaai10.pdf · ✓ https://www.cs.cmu.edu/~tom/pubs/NELL_aaai15.pdf | Read the web 24/7 for about 8 years. It started from an ontology (categories and relations) plus about 10 seed examples each, and learned extraction patterns by bootstrapping. | **Semantic drift** is its main failure mode. One bad pattern ("cities such as X" catching "X = Tokyo Disney") brings in bad instances, those train more bad patterns, and the errors compound. NELL limited this with **coupled constraints**: mutual exclusion (city ⊥ sports team), type checking of relation arguments, and agreement among several *independent* extractors (text patterns, HTML lists, morphology). It also promoted only the top few beliefs per iteration and used about 5 minutes per day of **human correction**. |
| **Knowledge Vault**, Google (KDD 2014). ⚠ https://dl.acm.org/doi/10.1145/2623330.2623623 | Fuses 16 web extractors with **priors from the existing KG** (path ranking and embeddings), then gives each triple a calibrated probability. | Do not trust a triple from extraction alone. Combine *how* it was read, *who* said it, and *whether it fits what is already known*. Keep everything below about 0.9 probability as "uncertain", not as false. |
| **Knowledge fusion**, Dong et al. (VLDB 2014). ✓ https://www.vldb.org/pvldb/vol7/p881-dong.pdf | Shows that many "conflicts" are really **extractor errors**, not source errors. | Model extraction error and source error **separately**. |
| **Knowledge-Based Trust (KBT)**. ✓ https://arxiv.org/abs/1502.03519 | Scores how trustworthy a source is from the *correctness of its facts* rather than its links (PageRank). It is a latent-variable EM over source accuracy and fact truth. | This gives **learned, per-source trust** that updates on its own. |
| **Truth discovery** (TruthFinder KDD'07 ⚠ https://dl.acm.org/doi/10.1145/1281192.1281309; Dawid–Skene 1979; LTM, Zhao VLDB'12; survey ✓ https://arxiv.org/abs/1505.02463; crowd EM ✓ https://www.jmlr.org/papers/volume11/raykar10a/raykar10a.pdf) | Alternates between estimating which values are true from weighted votes and estimating each source's weight from its accuracy. Dawid–Skene learns per-source confusion matrices. LTM handles *multi-valued* attributes and keeps false positives and false negatives separate. Later methods account for **source copying**. | Two "independent" sources are often one source copied. Independence has to be *estimated*, not assumed. Silence is weak negative evidence. |
| **Bitemporal DBs and temporal KGs** (SQL:2011 valid time plus transaction time; Wikidata qualifiers ✓ https://www.wikidata.org/wiki/Wikidata:Introduction; YAGO 2/4 time and space scoping ✓ https://yago-knowledge.org/) | Each fact carries *valid time* (when it is true in the world) and *transaction time* (when we believed it). Wikidata stores ranked statements (preferred, normal, deprecated) with references and qualifiers. | Never overwrite a fact; close its interval instead. Many apparent "conflicts" are just two different time slices. |
| **DBpedia Live** (pointer only, Wikimedia-derived) | Streams the edit feed, re-extracts only the changed items, and publishes changesets. | Prefer **event-driven delta updates** over re-crawling. |
| **Focused crawling**, Chakrabarti et al. 1999 (⚠ https://www.sciencedirect.com/science/article/pii/S1389128699000523), plus best-first and RL crawlers | Uses a topic classifier and a "distiller" (hub scores) to rank the crawl frontier, so the crawler spends its budget on pages likely to be relevant. | Forge's resonance score can be the frontier priority. Also add **link-context scoring** and hub learning. |
| **OpenIE / KnowItAll / TextRunner** (✓ https://homes.cs.washington.edu/~etzioni/papers/knowitall-aij.pdf) | Domain-independent extraction using Hearst patterns ("X such as Y"), with **PMI assessment through search hit counts** (redundancy). TextRunner extracts arbitrary (arg, rel, arg) triples in one pass. | Use redundancy across many phrasings as a signal. Open relations need **canonicalization**, or the same fact splits into many. |
| **Cyc** (✓ https://www.cyc.com/) | About 40 years of hand-built logic organized into microtheories (contexts). | **Contexts and microtheories** let contradictory beliefs coexist (fiction, past, jurisdiction). Purely hand-built knowledge does not scale. |
| **FEVER** (✓ https://arxiv.org/abs/1803.05355, ✓ https://fever.ai/) | Claim → retrieve evidence → label SUPPORTED, REFUTED, or NOT-ENOUGH-INFO. | You need a **three-way verdict** plus *refutation* evidence. Forge's zero-admit result is a missing NEI path. Its false admits come from "topical similarity ≠ entailment". |
| **Continual learning** (EWC ✓ https://arxiv.org/abs/1612.00796) | Protects important parameters when learning new tasks. | Forge has no weights, so it avoids catastrophic forgetting by construction. The equivalent risk is **lexicon or phase drift**, which needs "consolidation" (freezing core-lexicon phases). |
| **Open- vs closed-world assumption** | Under a closed-world assumption, "not in the KB" means false. Under an open-world assumption it means unknown. NELL and Knowledge Vault used a *local* CWA: if a functional relation already has a value, a different value counts as negative evidence. | Use OWA overall and LCWA for functional relations. That gives free negative examples. |
| **KGQA** (semantic parsing to SPARQL, templates, path search) | Turns a question into a typed query graph, then executes it against the KG. | Answer from the **store by query**, not by matching sentences at question time. Fall back to crawling only on a miss. |
| **Feeds**: Common Crawl ✓ https://commoncrawl.org/ · WebSub ✓ https://www.w3.org/TR/websub/ · RSS/Atom, sitemaps `<lastmod>` | Push-based subscriptions (WebSub) and monthly bulk snapshots. | Use push first, then sitemap diffs, then focused crawling. Common Crawl works for cold-start backfill. |
| **VSA / HDC / HRR / FHRR** (✓ https://arxiv.org/abs/2111.06077, ✓ https://arxiv.org/abs/2106.05268; Plate 1995 HRR; Plate's FHRR) | Concepts are high-dimensional vectors. Binding is ⊗, bundling is +, and similarity is the cosine. In **FHRR** each component is a unit phasor e^{iθ}: binding adds phases, unbinding subtracts them, and similarity is the mean cos(Δθ). | **This is Forge's nearest relative.** Forge's θ=(Φ−1)·40° is a 9-level quantized phasor, close to a 1-D, 9-state FHRR (or a "cyclic group" VSA, Z₉). |
| **Resonator networks** (✓ https://arxiv.org/abs/2007.03748) | An iterative "resonance" search that factors a bound vector s = a⊗b⊗c back into its codebook atoms by cleaning up each factor in parallel until the system settles. | This is a principled version of "answer via resonance". An answer is the *fixed point* that a query vector settles into. Convergence or non-convergence is itself a confidence signal, and it maps naturally onto Echo. |
| **Oscillatory binding** (binding-by-synchrony, Shastri's SHRUTI, phasor associative memories, Kuramoto networks) | Variables bind when they fire in phase. Inference spreads as phase-locked waves. | Gives prior art for "phase = role binding" and for coherence C as phase-locking value. |

## 2. What the design is missing (ranked)

1. **Separate source trust, extractor reliability, and fact truth, each learned with EM (KBT / Dawid–Skene / Knowledge Vault).** The rule "two sources agree" is gameable (copied sources, content farms) and too strict for niche facts, which is why you saw false admits followed by zero admits. Fix: score each fact by P(true | votes weighted by trust, extractor accuracy, and copy-detection). Admit when the posterior exceeds the threshold, not when a fixed count is reached.
2. **Coupled constraints against drift (NELL).** Add a type signature to every relation, mutual exclusion between categories, functional relations (one capital per country at a time), and value ranges. A candidate that violates a constraint gets *negative* resonance. This is the main missing guard against the false admits.
3. **A three-way verdict with negative evidence (FEVER, LCWA).** Use SUPPORT / REFUTE / NOT-ENOUGH-INFO. Sentence matching measures topic, not entailment. Require role-aligned matches (subject, relation, and value all bind), check for negation and modality, and allow "unknown" as an honest answer. Zero admits should come out as NEI with a crawl request, not as silence.
4. **A provenance graph.** Every fact links to (source URL, retrieval time, extractor, exact span, and the hash of the page version). This makes it possible to retract everything derived from a source when that source's trust collapses, and to explain answers.
5. **Bitemporal scoping.** Store valid_from/valid_to (world time) alongside recorded_at and last_checked (belief time). Treat "conflicts" between different time slices as successions, not contradictions. SPC decay should act on *belief confidence* (transaction time), never on valid time.
6. **Pattern bootstrapping with conservative promotion.** Learn extraction patterns from admitted facts. Promote only the top-k new patterns and facts per cycle, require each pattern to have high precision on known facts, and retire patterns whose precision drops.
7. **Ontology and canonicalization.** Entity resolution (aliases → one ID) and relation canonicalization, or the lexicon fragments.
8. **Active learning.** Send the most uncertain, highest-impact items to Nic: about 5 per day, as NELL did, or as one-tap questions in the app.
9. **Contexts / microtheories (Cyc).** Keep separate spaces for fiction, opinion, jurisdiction, and forecast so they do not contaminate world facts.
10. **Change detection and push updates.** Use WebSub, RSS, sitemap lastmod, ETag/If-Modified-Since, and content hashes. Re-verify on change *or* on decay, whichever comes first. Volatile relations (prices, officeholders) should get shorter half-lives than stable ones (birthplace), so the half-life is per relation, not a global 168 h.
11. **Lexicon consolidation.** Freeze the phases of core words and allow only newly learned words to move. This is the EWC idea without weights, and it prevents phase drift in the lexicon itself.
12. **Evaluation harness.** Keep a held-out gold set and track admit precision, recall, and NEI rate every day. NELL measured precision by category and caught drift that way.

### Mapping to Forge concepts
- **Phase Φ / θ** → the binding role. Encode fact = subject ⊗ relation ⊗ value as phase addition, (θ_s+θ_r+θ_v) mod 360°, following FHRR. The forbidden 5→8 jump becomes a **type constraint**: illegal role transitions are coupled constraints.
- **Coherence C ≥ 0.87** → the trust-weighted posterior from truth discovery, *multiplied by* a constraint-satisfaction term. C is a phase-locking value across independent evidence vectors (mean resultant length of their phasors).
- **Drift ≤ 0.35 / hard stop 0.8** → NELL semantic drift, measured as the phase distance between a candidate pattern or concept and its seed centroid. When drift rises, stop promoting patterns from that cluster.
- **Quarantine** → the NEI or conflict bucket. Release items by posterior, by active-learning answers, or by time-slice resolution. Release is *not* "2 sources agree".
- **SPC decay (168 h)** → per-relation volatility half-life applied to belief confidence. A decay crossing a threshold triggers re-verification and sets the crawl priority.
- **Echo ≥ 0.85** → the resonator-network check. Unbind the answer from the question's query vector, recompose it, and compare with the original question. If the iteration did not converge, the answer is not admitted.

## 3. Revised algorithm (plain steps)
1. **Intake.** Push feeds (WebSub, RSS) and sitemap diffs feed a frontier. The frontier is ranked by resonance with open questions, quarantine items, and decayed facts, times source trust, times freshness need.
2. **Fetch and version.** Store a content hash and a timestamp, and skip pages that have not changed.
3. **Extract.** Run several *independent* extractors (patterns, tables/lists, structured data such as schema.org JSON-LD). Each emits (subject, relation, value, valid-time, span, extractor).
4. **Canonicalize.** Resolve entities and relations to IDs; send new words to the lexicon with a provisional phase.
5. **Constrain.** Apply type, mutual-exclusion, functional, and range checks, plus the phase-jump rules. A violation adds negative evidence; it is not just a rejection.
6. **Fuse.** Run EM truth discovery: estimate fact posteriors given source trust, extractor accuracy, and copy-detection; LCWA supplies negatives. Then update source trust.
7. **Temporal reconcile.** If a new value overlaps an existing functional fact in time, close the old interval when there is evidence of succession; otherwise quarantine both.
8. **Admit.** Admit when the posterior C ≥ 0.87, there are no violations, drift ≤ 0.35, and evidence comes from at least 2 independent *estimated* source clusters (or 1 high-trust primary source). Otherwise send the item to quarantine with the reason.
9. **Bootstrap.** Mine patterns from newly admitted facts. Promote the top-k by precision on gold and admitted facts, and halt a cluster at drift 0.8.
10. **Decay and re-verify.** Belief confidence decays with a per-relation half-life. Below a threshold, the fact is re-queued as a crawl target. Retraction cascades through provenance.
11. **Answer.** Parse the question into a phase-bound query, then resonator-iterate against the store (KGQA). If it converges and Echo ≥ 0.85, answer with provenance and valid-time. If not, answer NEI and spawn a focused crawl.
12. **Human loop.** Send Nic a daily batch of the most uncertain, highest-impact quarantine items. His answers become gold labels and trust updates.

## 4. What's genuinely novel in Forge
- **Not novel:** a never-ending learner (NELL), web fusion with source trust (Knowledge Vault, KBT), bitemporal facts, focused crawling, and vector-symbolic binding (FHRR) are all established.
- **Plausibly novel:**
  - A *discrete, 9-state phase lexicon* (a Z₉ cyclic VSA) that grows from input and serves as the *only* representation, with no neural embeddings.
  - Hard **admission gates expressed as phase geometry**: coherence, drift, and Echo.
  - Forbidden phase transitions used as an ontology constraint language.
  - SPC statistical-process-control decay driving re-verification.
  - Echo as a round-trip self-consistency gate for QA.
  - The whole system on mobile and fully symbolic.

  Nothing I found combines FHRR-style phase binding with NELL-style coupled bootstrapping and KBT-style trust in one system. The two most-cited nearest relatives are FHRR (phasor binding) and resonator networks (answer-by-resonance factorization).
- **Risk to watch:** a 1-D 9-state phase has very low capacity. Standard VSAs use thousands of dimensions so that random codes are nearly orthogonal. Expect collisions (false resonance) as the lexicon grows unless each concept gets a *vector* of phases (for example, 256–1024 components each in Z₉). That collision effect may be a hidden cause of the false admits.
